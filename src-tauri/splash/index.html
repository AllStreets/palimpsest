Looking for the engine

The engine is not running

Palimpsest draws your city from a small engine that runs in the background on this Mac. Starting it installs it as a launch agent, so from then on it starts with your Mac.

macOS is keeping this app out of Downloads

The engine runs from the Palimpsest source in your Downloads folder, and this app is not allowed to open it yet. Turn on Downloads for Palimpsest in System Settings, then start the engine again, or run the By hand line below in Terminal.

Setting
Privacy & Security › Files and Folders › Palimpsest › Downloads
Address
127.0.0.1:4770
Log
~/Library/Application Support/Palimpsest/logs/engine.log
By hand
node bin/palimpsest.mjs engine install
